## 재사용할 성공 경로

1. 정상 게시봇 프로필을 유지하고 새 네이티브 작성기에 확정 원고 입력.
2. native 사진 선택기 전에 filechooser 대기를 준비; 업로드 직후 ALT/LINK 도구를 Enter로 열고 실제 제출 버튼으로 확정.
3. 대표 이미지 DOM 클릭이 실제 선택을 만들지 않을 때 현재 화면을 확인하고 네이티브 스크롤로 표지 상단을 보여준 뒤 대표 배지를 클릭. 어두운 체크 배지를 시각 확인한다.
4. 모드 전환을 누르기 전에 mode-confirm.mjs를 준비한다. 확인 창을 여는 클릭 완료부터 기다리지 않는다.
5. 실제 보이는 CodeMirror textarea만 선택한다. 네이티브 이미지 코드는 메모리에서 보존하며 요약 배경·3배너·평문 고지·크기만 보정한다.
6. HTML 붙여넣기 후 기본모드 전환을 완료하여 내용을 반영한다. 완료 버튼 Enter → 공개 → 현재 확인한 홈주제 → 발행1회.
7. actual public media는 lazy load이므로 정상 스크롤 후 확인한다. 0px 초기 상태만으로 실패를 단정하지 않는다.

- createBrowserTab visibility 옵션 지원 안 됨. 선택된 브라우저 tabs.new()+goto로 공개 확인 탭을 열어 해결. 작성기 실패나 Mac 잠금으로 해석하지 않는다.

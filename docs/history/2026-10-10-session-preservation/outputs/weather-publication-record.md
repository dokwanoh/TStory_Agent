## 이번 환경에서 확인한 성공 경로

1. 공식 근거·독자 질문·상품 관련성과 옵션을 확정한 뒤 원고와 6개 자산을 생성했습니다.
2. 미디어 삽입 단계에서 첫 작성기 작업이 3회 실패해 원고·자산·오류 기록을 보존했습니다. 기존 작성기를 직접 닫고 새 네이티브 작성기 하나에서 재입력했습니다.
3. 새 작성기의 복원 확인창은 실제 Chrome 네이티브 AX의 취소 버튼으로 닫았습니다. Mac 잠금으로 판단하지 않았습니다.
4. 네이티브 편집기에 원고를 입력한 뒤 최신 AX의 본문 번호로 각 이미지 자리 표시자를 선택했습니다. 매번 메뉴를 연 뒤 최신 AX의 실제 사진 메뉴 번호를 사용하고, filechooser를 먼저 대기시킨 뒤 클릭했습니다. 사진 업로드 후 네이티브 이미지 링크 팝업에서 링크를 적용했습니다. 총 6개 미디어 모두 성공했습니다.
5. 표지를 대표 이미지로 선택하고 IT 분류와 6개 태그를 완료했습니다. 공개 설정의 대표 이미지 미리보기에서도 표지를 확인했습니다.
6. 후반 HTML 전환 때 확인창 처리 도구를 사용했습니다. 현재 네이티브 이미지 코드 6개는 원문 그대로 보존하고, 고지문·쿠팡 배너 3개·요약 배경·본문과 제목 크기·버튼 서식만 보정했습니다.
7. 저장 직전 확인을 한 번으로 묶고 실제 최종 게시 버튼을 한 번 클릭했습니다. 관리자 목록에서 post229 생성 및 공개 게시물의 제목·시각·내용을 확인했습니다. 다시 저장하거나 재게시하지 않았습니다.
8. 공개 게시물 댓글창에서 상품명·선정 이유·링크 댓글 한 개를 등록하고 실제 표시를 확인했습니다. 웹 홈에서 실제 도입문 요약과 표지를 확인했습니다. 홈 썸네일의 링크는 해당 게시글 주소이며 상품 링크가 아닙니다.

재사용 시 좌표·AX 번호 자체를 복사하지 말고 현재 화면에서 다시 얻습니다. 정상 작동한 네이티브 사진 메뉴/filechooser/이미지 링크 순서는 유지합니다.

## 실패 이력과 재시도하지 않을 조건

- 첫 작성기에서 추정 role 이름, 오래된 AX 번호, 사진 메뉴 호출 실패가 이어졌습니다. 이 경로를 반복하지 않습니다. 최신 AX 관찰 없이 번호를 재사용하지 않습니다.
- 복원 확인창이 남았을 때 browser focus timeout이 발생했습니다. timeout만으로 Mac 잠금이라고 판단하지 않습니다. 실제 네이티브 창과 대화상자를 확인합니다.
- 선택적 ALT 보조작업의 iframe 접근 및 좌표 방식은 실패했습니다. 표지 ALT만 완료했습니다. 이를 이미 성공한 링크/업로드 실패로 오인하지 않고 업로드를 반복하지 않았습니다.
- 로컬 file URL로 GIF를 여는 시도는 브라우저 정책에서 거부됐습니다. 우회하지 않고 요청된 정상 게시 후 공개 HTTPS GIF 재생으로 확인했습니다.

상세 오류는 work/weather-editor-errors.md에 남겼습니다. 이 문서의 ‘성공 경로’는 위 실제 통과한 작업 순서에만 적용합니다.

## 확인 한계

- 티스토리 앱 화면은 직접 확인하지 못했습니다. 앱 홈 요약은 **미확인**입니다.
- 모바일 viewport 설정을 요청했으나 관찰된 실제 페이지는 1200×649로 유지됐습니다. 설정을 복원했고 휴대전화에서 실제 검증했다고 보고하지 않습니다. 생성 자산의 한글·수치·화살표·잘림은 시각적으로 확인했지만 실기기 모바일 렌더링은 미확인입니다.
- 표지 외 5개 미디어의 ALT 보조입력은 완료하지 못했습니다. 본문 링크와 미디어 로딩은 완료됐습니다.
- 자동 광고가 여러 곳 보이는 현상은 기존 스킨의 광고 표시입니다. 이번 수동 쿠팡 배너는 3개입니다. 전역 자동 광고 설정은 변경하지 않았습니다.

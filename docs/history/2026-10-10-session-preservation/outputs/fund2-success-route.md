# post227 — 성공 경로

태그: **성공 경로**

## 재사용할 순서

1. 먼저 게시물 관리 목록에서 기존 글의 공개 상태와 post ID를 확인한다. 이미 공개되어 있으면 새 게시물을 발행하지 않고 그 글을 이어서 보완한다.
2. 편집기 UI가 반복해서 막히면 원고·미디어·오류 정보를 보존하고, 사용자가 지시한 대로 게시봇 프로필에서 새 네이티브 작성기를 바로 연다. 티스토리가 복원한 저장 원고를 사용한다.
3. 현재 정상 작동하는 네이티브 기본모드를 유지한다. HTML 모드 전환을 추가하지 않는다.
4. 공개 페이지와 편집 상태를 대조해 실제 누락된 항목만 보완한다. 이미지 업로드가 이미 끝난 자산은 다시 올리지 않고, 누락된 제휴 연결은 네이티브 이미지 링크 UI로 추가한다.
5. 저장/공개 동작은 한 번 실행한다. 결과가 지연되거나 불확실하면 다시 누르지 말고 게시물 관리 목록과 기존 URL에서 post ID와 공개 상태를 확인한다.
6. 공개 본문에서 고지문과 배너 위치, 미디어 링크, 작성자 댓글, 웹 홈 요약을 확인한다. 앱을 보지 못했으면 앱 확인은 미완료로 기록한다.

## 반복 실패에서 바꾼 점

- 반복해서 같은 네이티브 작성기 UI를 두드리는 대신 새 작성기를 열고, 저장된 원고를 복원한 다음 문제 부분만 처리했다.
- 이미지 링크가 빠진 세 자산만 보완하고 정상 연결된 자산은 건드리지 않았다.
- Mac이 잠겼다는 근거는 없었다. 이번 UI 실패를 Mac 잠금으로 기록하거나 진단하지 않는다.
- 이번 경로는 실제 공개 게시물에서 결과를 확인했으므로 성공 경로로 기록한다. 다만 앱 요약과 GIF 재생 시간/가독성은 미확인이다.

## 실패 원인과 재시도하지 않을 조건

- 자동저장 복원 confirm이 입력을 막았음. 잠금 화면이 아니었다. 새 글에서는 이전 자동저장 안내 여부부터 확인하고 취소한다.
- AX 상태가 diff이면 본문 요소 번호를 찾을 수 없었다. 업로드 helper의 본문 찾기는 `disableDiffing:true`로 한 번 가져온다.
- 이미지 도구가 고정 상단 바 뒤에 가려지면 DOM 클릭으로 팝업이 열리지 않는다. 실제 화면에서 이미지와 도구 위치를 확인하고 소량 네이티브 스크롤로 도구를 드러낸 뒤 클릭한다. 같은 가려진 위치를 무작정 반복하지 않는다.
- 표 직후 마커 선택이 마지막 셀을 선택하는 현상이 있었음. 인포그래픽 코드가 셀에 들어가고 원래 마지막 답이 사라졌다. 후반 HTML에서 코드 자체를 보존해 표 밖으로 이동하고 확정 답을 복구했다. 다음에는 표 바로 뒤 이미지 위치를 전용 빈 문단으로 명확히 나누고 원래 셀 내용이 바뀌었는지 해당 부분만 확인한다.
- CodeMirror HTML의 locator.fill은 표시된 원문 상태에 반영되지 않았음. 성공한 방법은 실제 키보드 전체 선택→텍스트 붙여넣기. 정상 네이티브 원고 입력 방식은 유지한다.
- 공개 직후 일부 매체가 티스토리 불법촬영물 검토 안내 이미지로 대체됐다. `complete`와 `naturalWidth>0`만으로 원본 표시 성공을 판단하지 않는다. 실제 크기·CDN 호스트·화면을 함께 확인한다. 이번에는 약 몇 분 뒤 새로고침으로 원본 표시가 확인됐다. 검토 중에는 재업로드·재게시로 우회하지 않는다.
- 해결되지 않은 동일 이슈 3회 반복 상황은 이번에는 없었다. 재발 시 확정 원고·자산·오류를 보존하고 기존 작성기를 닫은 뒤 새 작성기 하나에서 시작한다.

# 국민참여성장펀드 2차 판매 중간 현황 — 근거 기록

## 주제 판단

- 허용 범위: 금융/보험.
- 독자 질문: 첫 5영업일 판매액이 공개된 뒤 판매 방식이 바뀌었는데, 지금은 무엇을 먼저 확인하고 가입 여부를 판단해야 할까?
- 한 문장 결론: 10월 8일부터 판매 제한이 사라졌지만, 5년 환매 제한과 원금 손실 가능성 때문에 판매 속도나 세제 혜택보다 장기 자금 여력부터 판단해야 한다.
- 관심 근거: 2차 모집 목표 6,000억 원 중 첫 5영업일에 3,301.6억 원(55%)이 판매됐고, 첫 펀드는 5일 만에 완판됐다고 금융위원회가 공개했다. 판매 실적은 관심의 관찰 근거이지 수익성이나 적합성의 증거가 아니다.
- 신선도: 금융위원회가 2026-10-08자로 첫 5영업일 판매 결과를 공개했다. 원문에 게시 시각은 표기되지 않았다. 확인 시각은 2026-10-08 19:34 KST; 날짜 기준 당일 공개이며 정확한 경과 시간은 확인 불가.
- 중복 검사: 최근 게시물 목록을 확인했고 Windows 하이브리드 AI, ChatGPT Intelligent UI, Anthropic Cyber Verification 및 Claude Haiku 5.5와 주제 중복이 없어 금융 주제로 전환했다. 최근 국민참여성장펀드 게시글은 목록에서 찾지 못했다.

## 확인한 공식 자료

1. 금융위원회, 「제2차 국민참여성장펀드 첫 5영업일간 판매 현황(9.30일~10.7일)」, 2026-10-08. https://m.korea.kr/briefing/pressReleaseView.do?newsId=156784623
   - 총 목표 6,000억 원, 판매액 3,301.6억 원(55%); 10/8부터 서민 우선배정 및 온라인 판매 비중 제한 없이 10/15까지 잔여 물량 소진 시까지 판매.
   - 서민의 첫 기간 가입액은 약 1,114.5억 원(전체 판매액의 33.8%). 서민 요건은 근로소득 5,000만 원 이하, 근로 외 종합소득이 있으면 종합소득 3,800만 원 이하.
   - 판매사별 배정 물량 조정.
2. 금융위원회, 「제2차 국민참여성장펀드 신청, 핵심만 빠르고 쉽게」, 2026-09-29. https://www.korea.kr/news/policyNewsView.do?newsId=148972715
   - 기간 9/30~10/15, 한도 연 1억 원·5년 총 2억 원, 최소 가입액 판매사별 10만/100만 원.
   - 1차 가입자는 2차 가입 제한; 2027년 이후 상품에는 가입 가능 안내.
   - 소득공제율 구간, 전용계좌, 직전 3개년 금융소득종합과세 해당 요건, 5년 환매제한, 3년 내 양도 때 세액 추징, 원금 비보장·고위험을 명시.
3. 금융위원회, 「제2차 국민참여성장펀드가 9.30일부터 2주간 일반국민 대상으로 판매됩니다」, 2026-09-08. https://fsc.go.kr/po010104/87667
   - 비상장 기업을 포함한 첨단전략산업 분야의 자펀드에 분산 출자하는 구조를 확인.

## 사용 상품과 이유

- 쿠팡 파트너스 API 검색: HTTP 200, rCode 0.
- 검색 질의: “투자 기록 노트 재테크 가계부”.
- 선택: 만년가계부 캐시북 금전출납부, 스프링 제본, 아이보리, 1개. 상품/옵션은 API 응답으로 확인했으며 가격은 본문에 싣지 않는다.
- 글과의 연결: 가입 전후로 가계 지출, 5년 내 필요한 자금, 투자 가능액을 종이에 기록·비교하고 싶은 독자에게 선택형 기록 도구로 유용할 수 있다. 펀드 가입 필수품이나 수익 보조 수단처럼 말하지 않는다.
- 작성자 댓글 이유: 5년 만기 상품을 검토하면서 생활비와 투자 가능 금액을 종이에 따로 기록해 비교하고 싶은 분이라면, 아이보리 1개 구성의 금전출납부를 예산 기록용으로 참고할 수 있어요.

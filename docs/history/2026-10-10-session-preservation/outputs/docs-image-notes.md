# 새 정지 이미지의 설명 계약

표지: Google 문서에서 AI 수정 후 원문 대조, 흰색/코발트/청록 명료한 토스 계열 구성. 큰 한글. 이전 사진 판별 돋보기/보라색 표지와 구별.
인포그래픽: 파스텔 손그림. 문단 선택→조건 적어 요청→수정 계획 승인→원문 대조. 행위자를 구분하고 조건 유지 채택/누락 되돌림을 표시.
1절: 문서와 옆 대화창을 한 작업 공간에서 사용하는 개념 실사. 공식 UI가 아님.
2절: 실제 문서에 쓰기 전에 승인 카드로 멈추는 개념 실사. 승인 우선 관계를 설명.
3절: 가정 예시의 원문/수정안에서 10월15일 오후6시·1인2만원·결제 후 신청완료가 유지되는 종이 비교도.
4절: 원문과 수정안을 비교하고 문제가 있으면 되돌리는 개념 실사.
네 장은 서로 다른 시점·색감·구도. 전혀 무관한 시장·연극·공장 비유 없음. 공식 화면이나 직접 사용 결과로 표현하지 않음.
제작: 내장 image_gen 실제 래스터6장. 원본 보존 후 JPEG 웹 압축, GIF 별도.

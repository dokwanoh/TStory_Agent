# MCP 모션 내용 계약

원고: mcp-article.md. 독자가 대화형 Claude Code에서 연결 상태와 실제 조회 결과를 구분하는 흐름.
서버·/mcp 상태 확인 → 상태 판단 → 재연결 중(기다림), 실패(오류 확인·수동 재연결), 인증 필요(공식 로그인) → 연결 상태 재확인. 미해결은 상태 판단으로 되돌아가며, 연결을 확인한 뒤 실제 조회·원본 제목과 누락을 대조한다.
SDK에는 같은 패널이 없다는 한계를 상단에 유지한다. 로컬 서버에 자동 재연결을 보장하지 않는다. 세 분기를 동시에 보여주는 것은 선택의 대안이며 동시 수행을 뜻하지 않는다.
설명 타임라인: 상태4초, 판단4초, 분기5초, 재확인4초, 실제 조회4초, 최종 전체 흐름 정지5초. 총26초. 처리 속도 아님.
AppKit/ImageIO 로컬 렌더러의 한글·노드·화살표를 편집 가능한 코드로 구성. GIF900×1100,260프레임. 대표 프레임 확인은 실제 재생 검사의 대체가 아니다.

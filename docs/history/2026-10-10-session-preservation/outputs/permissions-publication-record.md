## 실패·수정과 재발 방지

- 사진 생성 초안이 설명력이 약해 절1은 읽기/편집/실행의 직접 도해로 교체. 주제와 연결되지 않는 사진을 그대로 쓰지 않는다.
- 대체 텍스트 버튼이 고정 메뉴 뒤에 가려짐. 화면 위치 확인 뒤 위로 0.3페이지 스크롤하여 해결. Mac 잠금으로 추정하지 않는다. 링크 대화창의 대체텍스트와 실제 이미지 alt는 별개로 처리.
- 쿠팡 HTML 복사 버튼 2회에서 현재 배너 코드가 아닌 이전 클립보드 내용 확인. 재복사 반복 대신 실제 렌더링된 배너 iframe 주소를 읽어 사용. 서명된 이미지 코드/키를 기록하지 않음.
- HTML → 기본모드 확인창은 기존 네이티브 대화상자를 수락하여 해결. 이미 열린 확인창을 재클릭하지 않음.
- 티스토리 일부 매체 검토 안내는 원본 변환 전 상태. 재게시·재업로드하지 않고 댓글·다음 조사 진행 후 원본으로 바뀐 것을 확인. 실제 GIF 재생까지 확인 후 완료 기록.

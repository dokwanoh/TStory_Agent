## 주제와 상품 선정 이유

독자의 질문은 “채팅방에서 받은 사진이 AI인지 확인하고 공유해도 될까?”다. 결론은 “지원 범위의 AI 표식을 확인한 뒤 원본 출처·날짜도 대조하며, 미검출을 실제 사진 인증으로 읽지 않는다”다.

Google 2026-10-07 공식 발표의 일반인 공개 확대를 기준으로 IT/소프트웨어 주제를 선정했다. 최신 다섯 글과 직접적인 주제 중복을 피했다. 발표 당일 시각·시간대는 공식 본문에 없으므로 정확한 36시간 이내 판정을 확정하지 않았다. 발표 날짜가 조사 전날이라는 확인 가능한 범위만 기록했다. 현재 수요 근거와 향후 관심 전망은 주제 검토 자료에서 구분했고 실제 Detector 이용량이나 미래 인기를 보장하지 않았다.

상품은 금준경 저자의 풀빛 종이책 《미디어 리터러시 쫌 아는 10대: 보이는 대로 보지 않는 법》이다. API 상품 4507403883, item 5418289388, vendor 72718209674, ISBN 9791161727820을 확인했다. 사진·영상 가짜뉴스와 출처 확인·다시 검색하기라는 실제 목차가 본문의 두 번째 확인 단계와 직접 연결된다. 초보 독자의 선택적 학습 자료이며, SynthID 사용 매뉴얼이나 필수 구매로 설명하지 않았다. 관련성이 약한 SSD 후보는 채택하지 않았다.

## 재사용할 편집 순서

1. 같은 게시봇 프로필에서 글 목록으로 중복·기존 저장 결과를 확인하고 편집창 하나를 연다. 과거 완료 글의 자동 저장 복원 알림은 현재 글의 복원으로 오인하지 않는다.
2. 확정 원고를 네이티브 기본모드로 입력한다. 문단별 독립 p, 주요 제목 h2, 본문 16px 평문, 주요 제목 23px 볼드, 핵심 문장 한 개만 본문 볼드로 설정한다.
3. IT 분류와 태그 6개를 입력한다. 확정 이미지 6개와 workflow GIF 1개를 해당 위치에 업로드한다.
4. 실제 표시된 이미지의 네이티브 도구로 ALT와 API 확인 제휴 링크를 각각 설정한다. 전체 DOM 이미지 순번과 현재 화면 AX 이미지 순번을 혼동하지 않는다.
5. 표지의 네이티브 대표 설정 버튼이 active인 것을 확인한다.
6. 검증된 모드 변경 확인 도구로 HTML로 이동한다. 네이티브 이미지 코드 7개를 보존하면서 요약표·비교표·정보 버튼·상중하 공식 배너·고지문만 보정한다. CodeMirror 입력 결과는 실제 선택·복사한 편집 내용으로 확인한다.
7. 기본모드로 돌아와 최종 확인을 한 번에 묶는다. 본문·수치·상품·미디어·서식·분류·태그를 통과한 뒤 발행 모달에서 공개·현재·댓글 허용·홈주제 IT 인터넷을 선택한다.
8. 공개 발행을 한 번 누른다. 저장중 표시 뒤 실제 관리 글 수·새 글 제목·공개 페이지를 확인한다. 불확실하면 기존 글부터 확인한다.
9. 실제 댓글창에서 작성자 상품 댓글 한 개를 등록하고 결과를 읽는다. 홈 썸네일 원본이 대표 표지와 일치하며 썸네일 링크가 게시글로 향하는지 확인한다.

## 실패·회복 기록과 다음 실행의 조건

- 관련성 약한 SSD: API 성공과 옵션 일치만으로 상품 관련성을 통과시키지 않는다. 원고 사실을 상품에 맞춰 바꾸지 않는다.
- 인포그래픽의 잘못 연결된 화살표와 서비스 제공사를 실제 생성 이미지 출처처럼 보이게 한 표기: 해당 두 이미지만 수정했다. 수정된 바이트와 Gemini 영상 구간 문장을 독립 검토하여 PASS를 받았다.
- ALT 도구의 바깥 DOM 버튼 클릭은 효과가 없었다. 실제 네이티브 AX 체크박스 도구로 해결했다. 효과 없는 외곽 버튼 클릭을 반복하지 않는다.
- AX 이미지 개수는 화면에 보이는 항목 수였다. 업로드 실패로 오인하지 않고 DOM 파일명으로 실제 업로드를 확인했다. 이미지가 이미 있으면 재업로드하지 않는다.
- HTML textarea의 이전 값은 CodeMirror의 실제 새 입력을 반영하지 않았다. 실제 선택·복사 내용은 최종 15,785자와 일치했다. 오래된 textarea 값만으로 붙여넣기 실패를 판단하지 않는다.
- 댓글 래퍼 entry222Comment는 DOM에 두 번 있으나 실제 댓글 comment19722342는 한 개다. 래퍼 중복이나 줄바꿈 정규화로 댓글을 중복 등록하지 않는다.
- 공개 이미지의 초기 loaded=false는 loading=lazy였다. 실제 각 절로 이동하자 모두 loaded=true가 됐다. 화면 밖 지연 로딩을 이미지 손상으로 기록하지 않는다.
- 같은 해결 불가 이슈 3회 반복은 발생하지 않았다. 편집창 재생성 조건을 발동하지 않았다.

## 한계와 증거 파일

실제 AI 사진 판별을 실행한 체험담은 아니다. 본문 예시는 명시적인 가정이고, 공식 발표·도움말의 조건을 설명한다. 공식 발표의 정확한 시각이 없어 엄밀한 36시간 판정은 미확정이다. 인기나 탐지 정확도를 보장하지 않는다. 공개 글의 남은 편집 문제는 확인되지 않았다.

- `synthid-topic-review.json`: 주제·상품 관련성 검토
- `synthid-combined-review.json`: 수정된 본문·미디어 PASS
- `synthid-final-check.json`: 저장 전 통합 확인
- `synthid-save-attempt.json`: 1회 저장 사전 기록
- `synthid-media-manifest.json`: 원본·최종 미디어와 해시·설명
- `synthid-workflow-contract.json`, `synthid-media/playback-*.png`: 실제 모션 재생 증거
- `synthid-public-proof.png`, `synthid-home-proof.png`: 공개 결과와 대표 이미지

이 경로의 성공은 post 222의 실제 공개 결과에 한정된다. 다음 글은 현재 화면·상품·원고·미디어를 새로 확인하며 이전 저장 성공이나 클릭 인덱스를 그대로 재사용하지 않는다.

# 훅 실패 판단 모션 계약
출처: hooks-article.md 절 1–3, 공식 v2.1.295 릴리스·훅 가이드. 실행 전 필수 훅에 실패 차단 정책을 선택한 가정 예시다. 일반 기본 동작이나 자동 복구를 표현하지 않는다.
입력: 독자가 소개 문구 수정·연락처 유지 조건을 정의. 검사 프로그램이 실행 전 판단.
세 갈래: 정한 범위 문제없음 / 조건 위반 거절 / 실행 불가·시간 초과 미검사. 상호 대안이며 순차 단계가 아니다.
문제없음은 진행 가능한 경우에만 작업 후 독자가 실제 결과를 원본과 대조. 거절은 독자가 조건 위반을 수정해 재검사. 미검사는 작업 중단 후 독자가 검사 기능을 복구·재확인. 두 실패 분기의 되돌림은 검사로 향한다.

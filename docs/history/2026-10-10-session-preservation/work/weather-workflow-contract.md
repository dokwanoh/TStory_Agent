# 날씨 workflow 확정

입력: 독자가 계획한 목적지·날짜·출발/활동/귀가 시간.
주체: 독자. 날씨 서비스는 예보를 제공하고 옷·일정을 자동 결정하지 않음.
노드1 목적지·날짜 선택 → 노드2 세 시간 기온 비교 → 노드3 바람·강수·특보 읽기 → 노드4 겉옷·일정 결정.
조건 분기: 특보가 있으면 공식 현장 안내를 함께 읽어 노드4로 합류. 없는 경우 기본 흐름으로 이동.
결과: 독자가 보유한 옷과 일정에 적용, 필요하면 출발 전 새로운 예보로 계획 조정.
타임라인: 0~4초 장소/날짜와 시간 비교, 4~8초 기온·바람·비, 8~10초 특보 분기, 10~14초 직접 판단, 14~18초 전체 흐름 정지 유지. 무한 반복.
검증 완료: 공개 post229에서 HTTPS GIF 로딩 후 한 주기 이상 관찰. 목적지 선택 강조 → 조건 분기 → 겉옷·일정 결정 → 전체 강조와 출발 전 갱신 안내 정지 구간을 확인. 한글·분기·화살표와 읽을 시간이 제작 계약에 맞음. 마지막 구간 화면은 outputs/weather-motion-proof.png에 기록.

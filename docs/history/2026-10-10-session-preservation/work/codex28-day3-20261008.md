# Codex 28일 업데이트 3일차 🎁 저장형 리셋, 계정에서 이렇게 확인해요

## 주제 결정
- 독자의 질문: Codex 28일 업데이트 3일차에 말한 ‘저장형 리셋’은 무엇이고, 내 계정에서 어떻게 확인할까?
- 한 문장 결론: GPT‑6의 대화형 UI는 ChatGPT Chat 업데이트이며, Codex/Work 모델은 그대로다. Codex·Work 유료 계정의 저장형 리셋은 Settings → Usage에서 조건과 만료를 확인한 다음 필요할 때 적용한다.
- 상품과의 구체적 연결: 청소년과 AI 답변·화면을 함께 읽는 보호자에게, AI가 만든 상호작용 화면과 정보의 출처·조건을 따져 보는 미디어 리터러시 책이 보조 읽을거리로 맞는다. 구매는 필수가 아니다.
- 상품 API 확인: `미디어 리터러시 쫌 아는 10대: 보이는 대로 보지 않는 법`, 도서 단품, Coupang API HTTP 200 / rCode 0, API 검색 결과 확인. 제휴 링크는 아래 기록 파일에만 보관하고 이미지·댓글 작업에 사용한다.

1. 3일차 업데이트, ChatGPT와 Codex를 나눠 봐요 📌

OpenAI는 10월 7일 공식 글에서 GPT‑6와 대화형 UI를 ChatGPT에 적용한다고 발표했어요. 대화형 UI는 질문에 따라 그림, 버튼, 표, 간단한 입력 도구를 답변 안에 보여주는 기능입니다. 설명을 글로만 읽는 대신 항목을 누르거나 값을 바꾸며 살펴볼 수 있어요.

Plus·Pro·Business·Enterprise에는 GPT‑6 Sol, Free·Go에는 GPT‑6 Luna가 적용된다고 안내됐어요. 앞의 네 요금제는 10월 7일부터, Free·Go는 10월 8일부터 순차 확대한다고 밝혔습니다. Enterprise는 관리자의 설정에 따라 달라질 수 있고, 실제 계정 반영 시점도 다를 수 있어요.

여기서 제품을 구분해야 해요. **이번 GPT‑6 대화형 UI는 Chat 탭에 적용되며, Work와 Codex를 구동하는 모델은 바뀌지 않습니다.** 그러니 ChatGPT에서 새 버튼이나 시각적 답변이 보여도, Codex 작업 모델이 함께 교체됐다고 해석하면 안 돼요.

2. ‘저장형 리셋’은 자동 초기화와 달라요 🔋

3일차 공지는 Codex와 ChatGPT Work를 합쳐 4천만 사용자 규모를 기념하며, 유료 계정에 저장형 리셋을 적재한다고 안내했어요. 이 숫자는 두 제품을 합친 규모이고, 공개된 정리에는 주간·월간 같은 집계 기간이 적혀 있지 않습니다. 따라서 Codex 단독 사용자 수나 월간 이용자 수로 바꿔 읽으면 안 돼요.

**저장형 리셋은 계정에 보관해 두었다가 사용자가 적용하는 1회성 초기화예요.** OpenAI 도움말에 따르면 사용하거나 만료될 때까지 계정에 남고, 구매한 크레딧처럼 현금 가치가 있거나 요금제의 상시 한도를 늘려 주는 것은 아니에요. 적용 대상과 만료 시점은 제공 건마다 달라질 수 있습니다.

자동·전체 초기화는 공지에 적힌 사용량 한도를 바로 갱신하지만, 저장형 리셋은 Usage 화면에서 직접 선택해야 해요. 전체 저장형 리셋을 적용하면 해당 계정의 5시간·주간 Codex 사용량 창이 갱신될 수 있고, 주간 초기화 날짜도 달라질 수 있습니다. 한도에 여유가 있다면 급하게 적용할 이유가 없어요.

3. 내 계정에 들어왔는지 확인하고, 적용 여부를 고르세요 ✅

**Settings → Usage에서 사용 가능한 리셋과 만료 시점을 먼저 확인하세요.** ChatGPT 데스크톱 앱이나 웹에서 이 메뉴를 열면 ‘1 reset available’ 또는 ‘Full reset’처럼 표시될 수 있어요. 적용 전에는 어떤 사용량 창을 갱신하는지도 확인합니다. 이미 한도에 걸렸을 때 선택지가 표시될 수도 있어요.

예를 들어 5시간 한도에 도달했지만 주간 한도에는 여유가 있다고 해볼게요. 화면에 전체 리셋이 보이면 이를 적용할 경우 두 사용량 창과 다음 주간 초기화 날짜에 영향을 줄 수 있습니다. 지금 이어서 해야 할 일이 있는지, 화면에 적힌 적용 대상을 확인한 뒤 직접 결정하면 돼요. 이 예시는 사용 화면의 일반적인 작동을 설명한 것이며 특정 계정의 실제 상태를 뜻하지 않습니다.

리셋이 바로 보이지 않는다면 같은 계정과 워크스페이스를 보고 있는지 확인하고 Usage 화면을 새로고침해 보세요. 그래도 없으면 지급 조건이나 배포 시점 차이일 수 있습니다. ‘유료 계정에 적재’라는 공지만으로 내 화면의 표시·만료일을 대신 확정할 수는 없으니, 계정에 보이는 안내를 기준으로 판단하는 게 정확해요.

Codex를 당장 많이 써야 하고 계정에 저장형 리셋이 표시된다면 조건을 읽은 뒤 적용을 고려할 수 있어요. 급하지 않다면 평소 사용량 초기화를 기다려도 됩니다. 이번 업데이트가 요금제의 기본 한도를 영구히 키우거나, 모든 계정에 같은 시각·같은 조건으로 반영된다는 뜻은 아니에요.

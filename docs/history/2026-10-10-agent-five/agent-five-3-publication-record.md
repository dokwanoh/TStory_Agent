## 실패·재발 방지
- Partners 사은품 첫 배너를 사용하지 않고 단권 카드로 전환. 카드 hover 버튼에 Enter만 보내면 무반응: 상품 이미지 클릭 후 보이는 생성 버튼 사용.
- iframe 기본모드에 figure.imageblock이 없다고 업로드 실패로 판정하지 않음. 실제 iframe body의6개 img·alt·부모 링크로 확인.
- DOM 이미지 선택과 화면 스크롤이 다른 동작: 동일 클릭을 반복하지 말고 정상 네이티브 스크롤 사용.
- browser file URL 정책 차단은 우회하지 않고 정상 작성기의 업로드된 GIF에서 재생 확인. Finder 접근 도구의 잠금 메시지로 실제 Mac 잠금을 단정하거나 사용자에게 잠금 해제를 반복 요청하지 않음. 브라우저 네이티브 작업은 정상 수행됨.

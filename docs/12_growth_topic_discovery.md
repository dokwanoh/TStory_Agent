# 성장 주제 탐색과 첫 실제 콘텐츠 검증

상태: 수요 우선 탐색으로 전환, 첫 공식 신호 조사와 잠정 후보 작성 완료. 사용자 경험 인터뷰는 철회했으며 답변을 기다리지 않는다. 기존 블로그는 중복·갱신 검토 자료로만 사용하고 미래 문체나 주제를 제한하지 않는다. 초기 증거는 `docs/13_demand_discovery.md` 참조.

## 목표와 작업 순서

1. 에이전트가 공개 수요 신호에서 넓은 주제 후보를 발견한다. 전 세계 관심은 발굴 자료로, 한국어 독자 수요는 현재 언어 설정에 맞는 별도 검증 대상으로 취급한다. 사용자의 과거 전문성은 필터가 아니다.
2. 해당 분야를 직접 학습하고 공식 자료 비교·재현 가능한 실제 테스트·독창적 종합으로 설명할 수 있는 구체 질문을 찾는다. 물리적 체험이나 수행하지 않은 실험은 주장하지 않는다.
3. 공개 검색 결과와 공식 자료로 독자 문제, 경쟁 콘텐츠의 미해결 질문, 출처 확보 가능성, 갱신 부담을 조사한다. 조회일·질의·관측 범위를 남기고 검색량이나 예상 유입을 만들어내지 않는다.
4. 비교표와 근거를 바탕으로 낮은 위험의 첫 콘텐츠 후보를 고른다. 아직 수익모델·예산·주제 제한이 미확정이면 잠정 판단으로 명시한다.
5. 실제 evidence pack → brief → draft → QA → 로컬 게시 패키지를 만든다. 고정 테스트 예제의 성공을 실제 콘텐츠 품질 검증으로 대체하지 않는다.

## 후보별 기록 양식

| 항목 | 기록할 내용 | 누락 시 처리 |
| --- | --- | --- |
| 독자와 문제 | 누가 어떤 상황에서 어떤 결정을 해결하려는가 | 대상 독자 불명확으로 보류 |
| 핵심 질문·검색 의도 | 첫 글의 질문 하나와 범위 | 범위를 먼저 축소 |
| 수요 단서 | 실제 조회한 공개 신호, URL·확인일·한계 | UNKNOWN; 검색량 추정 금지 |
| 경쟁 공백 | 관측한 비교 대상이 답하지 못한 구체 질문 | 차별화 가설로만 유지 |
| 독창적 증거 | 직접 실험·비교 자료·재현 가능한 예시·허용된 경험 | 조사형으로 범위 조정하거나 보류 |
| 출처 | 핵심 주장별 공식 출처와 최신성·충돌 여부 | 주장 축소 또는 보류 |
| 기존 자산 관계 | 63개 기존 글과 검색 의도 중복 여부 | update/merge/differentiate 검토 |
| 제작·갱신 부담 | 필요한 실제 작업, 관측된 시간 또는 UNKNOWN | 비용·지연 숫자 조작 금지 |
| 위험·수익 | 고위험 여부, 고지 필요성, 수익모델의 확정 여부 | 고위험은 기본 제외, 수익은 UNKNOWN |
| 판정 | 진행/추가조사/보류, 이유와 뒤집을 조건 | 불확실한 항목을 0점 처리하지 않음 |

이 양식은 조사 설계이지 후보별 평가 결과나 새 런타임 점수 모델이 아니다. 근거가 없는 상태에서 숫자를 곱해 정밀한 순위를 만들지 않는다. 후보 선정 후 필요한 필드는 기존 TopicCandidate/ContentOpportunity 계약에 연결한다.

## 첫 실제 글의 합격 기준

- 특정 독자의 핵심 질문에 직접 답하며 제목과 본문이 일치한다.
- 사실 주장과 출처·확인일이 연결되고, 출처가 실제로 해당 주장을 뒷받침하는지 사람이 검수한다.
- 경험 주장은 소유자 진술만으로 통과시키지 않는다. 증거·공개 범위를 확인하거나 1인칭 경험 표현을 제거한다.
- 기존 이미지 139개는 권한 미확인이므로 자동 재사용하지 않는다. 불필요한 이미지는 생략할 수 있다.
- 고위험 조언, 수익 예측, 입증되지 않은 우월성이나 체험을 넣지 않는다.
- 새 기사 입력으로 dry-run·품질 게이트·재실행·로컬 렌더링을 검증하고 artifact를 기록한다.
- 결과는 내용 검토를 위한 로컬 패키지다. 게시·예약·로그인·업로드 또는 신규 비용은 포함하지 않는다.

## 현재 증거 한계

공식 급상승 관심 신호의 첫 관측은 확보했으나 절대 검색량·지속 수요·향후 유입·수익·경쟁 공백은 아직 미검증이다. 공개 자산 점검에서 관측한 링크 개수나 과거 주제 빈도를 성장 잠재력으로 환산하지 않는다.

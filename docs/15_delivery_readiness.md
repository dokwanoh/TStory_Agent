# 전체 진행률과 실전 준비도

기준일: 2026-09-07. 근거: PLAN.md, STATUS.md, 실제 로컬 artifact, 첫 편집 파일럿의 독립 검수 기록. 이번 평가는 범위를 설명하는 관리용 추정이며 측정된 노동시간·비용·유입 달성률이 아니다.

## 요약

- 전체 M0–M6 구현·운영 준비도: 약 **30~40%**라는 보수적 추정. 정밀한 작업량 산정이나 고정 가중치 모델은 아직 없다.
- 좁게 정의한 합성 fixture 기반 Offline MVP: 기존 exit gate 통과. 실제 원고의 실전 투입 준비까지 완료됐다는 뜻은 아니다.
- 첫 실제 원고: 근거 조사·작성·독립 검수·수정 후 재검수까지 진행. 권리 보류 2건, 최종 표현물·렌더링·인간 감사·게시 승인 미완료.
- 후속 편집 결정: 기차표는 권리 보류를 유지하고 PDF 연구는 선택적 항목으로 내렸다. 새 수요 비교를 거친 ‘제미나이 출처 확인법’은 실제 입력→검수 전용 후보 생성, 독립 편집 검수와 데스크톱 화면 검수까지 통과했다. 정확한 반응형/확대/접근성 전체 검증과 인간 소유권 경계·로컬 패키지 검수·게시 승인은 남아 있다. 개별 검색량은 UNKNOWN이다.
- 유입·수익 목표 달성률: **UNKNOWN**. 프로젝트 신규 게시와 방문자 노출 실험을 하지 않았으며 기존 블로그의 실제 트래픽도 측정하지 않았다.

M0–M2 문서에 완료가 표시됐다는 이유로 단순히 3/7=43%라고 계산하지 않는다. 이 완료는 각각 정의된 공개 조사·설계·합성 로컬 테스트 범위이며, 뒤의 게시·관측·성장 단계는 별도의 운영 검증과 관찰 기간이 필요하다. 테스트 수나 문서 수로 전체 진행률을 올리지 않는다.

## 바로 다음 로컬 작업

최신 우선순위: `content/pilots/gemini-source-check/verification.md`에 기록한 실제 글의 미완료 화면·접근성 검증. 아래 첫 계절성 원고 관련 설명은 해당 원고의 보류 조건으로 보존한다. 새 Gemini 후보는 생성 가능하지만 검수 전용이며 승인 패키지가 아니다. Safari 개발자 메뉴를 켜는 설정 변경은 승인 대기이며, 이전 합성 글의 모바일 검수 결과를 전용하지 않는다.

1. `prepare-review`로 승인 패키지가 아닌 후보 원문 JSON을 확인할 수 있게 됐다. 이를 실제 독립 검수와 최종 렌더링 확인에 사용해야 한다. Markdown 검수를 서로 다른 생성물의 승인으로 재사용하지 않는다. 실제 파일럿은 권리 보류 때문에 아직 후보 생성 대상이 아니다.
2. 검수 누락·원고 변경·검수/근거/정책 기한 만료 차단은 구현됐다. 실제 파일럿에 대해서는 검수를 수행하고 근거 있는 기한을 정해야 한다. 입력의 과거 확인일을 현재 시각으로 대신하지 않는다.
3. 보류를 해제하지 않고도 진단을 확인하고 수정할 수 있게 유지한다. 권리 검토와 최종 렌더링/링크/인간 감사는 독립 조건으로 둔다.
4. 첫 계절성 글을 억지로 게시하지 않는다. 상시 수요 후보를 비교하고, 직접 재현 가능한 실험과 독창적 설명이 가능한 다음 파일럿을 선정한다. 아직 자동으로 수요를 찾고 배우고 쓰는 반복 운영 시스템이 완성된 것은 아니다.

이 로컬 작업은 외부 권한 없이 진행할 수 있다. 후속 구현은 docs/06_tdd_and_evals.md의 추가 acceptance를 Red부터 검증한다.

## 승인이 필요한 시점

실제 티스토리 최초 쓰기, 비공개 분석 연결, 비용 발생/설치, 자동 게시 모드 승격은 각각 별도 승인이다. ‘계속’은 이 경계를 해제하지 않는다. 예산·수익화·승인 방식처럼 소유자만 결정할 수 있는 사항은 필요해지는 시점에 한 번에 하나씩 질문한다. 주제와 전문지식 조사는 에이전트의 책임이다.

남은 기간은 아직 추정하지 않는다. 플랫폼 경로·권한·운영 표본·관찰 기간을 확인해야 하며, 코드 완료만으로 검색 성과를 보장할 수 없다.

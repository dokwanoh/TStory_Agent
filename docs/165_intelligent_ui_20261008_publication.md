## 성공 경로와 재발 방지

1. 기존 게시봇 프로필에서 실제 관리자 상태를 확인하고 신규 제목 중복이 없음을 확인한다. 과거 작성기 종료 기록은 현재 작업의 중단 지시가 아니다.
2. 네이티브 작성기 한 개에 문단을 넣고 번호 제목만 제목1(H2)로 지정한다. 실제 분류·태그 값을 확인한다.
3. 문서 순서대로 새 이미지를 업로드한다. 삽입 마커는 업로드 전에 지운다. 파일 선택 대기를 먼저 건다.
4. 새 이미지의 실제 노드를 클릭한 뒤 ALT 제출과 IMAGE 링크 제출 도구가 열렸는지 확인한다. 일반 본문 링크 도구의 비활성 상태를 잠김으로 판정하지 않는다.
5. 표지의 대표 선택 표시를 직접 확인한다. 네이티브 이미지 코드를 보존한 후 HTML 모드에서 제목·본문·고지문 서식, 배너·표·정보 버튼을 마무리한다.
6. 작성 모드 변경은 변경 클릭과 실제 확인 대화상자 수락을 함께 처리한다. 이번 양방향 변경은 잠김이나 인터럽트 없이 완료됐다.
7. 공개 분류는 오래된 버튼 접근성 이름보다 현재 선택된 자식 텍스트를 기준으로 확인한다. 저장 시도 기록 후 공개 버튼을 한 번 누르고 관리자로 돌아온 결과를 기다린다.
8. 댓글 등록도 한 번 실행하고 실제 새 댓글 ID로 확인한다.
9. 이미지 지연 로딩은 한 화면씩 순서대로 스크롤해 확인한다. 여러 화면을 건너뛴 뒤 미로딩 이미지를 게시 실패로 판정하지 않는다.
10. 본문·OG·홈 이미지의 resize URL은 fname을 풀어 원본 경로끼리 비교한다. 표현 방식 차이로 대표 표지가 틀렸다고 오판하여 재저장하지 않는다.
11. 홈의 rep0 이미지 이름은 여러 카드에서 반복된다. 현재 글의 고유 링크 아래 이미지로 범위를 좁힌다.
12. 최종 공개 상태와 이력을 확정하면 작업을 종료한다. 예약·자동 게시 일시정지는 유지한다.

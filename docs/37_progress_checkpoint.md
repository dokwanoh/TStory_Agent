# 2026-09-13 전체 진행률과 남은 완료 조건

## 요약

전체 TISTORY GROWTH OS 기능 준비도는 **약40~50% 진행,50~60% 잔여**로 추정한다. 계측된 공수 비율이나 테스트 개수의 비율이 아니다. 완료한 로컬 계약·설계·보조 게시 경험과, 미완료한 독립 운영·성과 학습을 구분하기 위한 넓은 관리용 범위다. 실제 유입 목표 달성률은 baseline과 목표값이 없어 UNKNOWN이다. 세계 최고 유입을 이 비율로 표현하지 않는다.

별도 질문인 “대화형 에이전트 없이 하루3편을 프로그램이 만든 뒤 예약·검증할 수 있는가?”의 답은 아직 아니다. 스킬과 에이전트가 성공한 작업이 독립 런타임에 모두 이전된 것은 아니다. 무인 운영의 남은 통합 작업은 현재 완료한 A–F 코드 조각보다 크다. 성공까지 남은 일수/비용은 대표 실제 실행을 계측하기 전에는 제시하지 않는다.

## 독립 프로그램으로 옮기는 순서

추가 결정 ADR-049: 아래2단계(정시 실행·복구)와3단계(성과·학습) 사이에 **이웃 블로그 댓글 소통 서브에이전트**를 예정 항목 BL-012로 둔다. 상세지침은 해당 단계에서 받으며 지금 생성·실행·댓글 게시하지 않는다. 기존 자동 댓글 금지 원칙과 게시 권한/정책 조건은 착수 전에 명시적으로 조정한다.

1. **고정 검수 패키지의 완전한 게시 경로**: 저장된 본문/네 이미지/alt/대표/태그/분류/예약 시각을 읽는 어댑터, 정상 입력/업로드/예약 어댑터, 동일ID 재검증. 합격은 프로그램의 실제1편 예약 완료이며 목록의 공개 설정이나 합성 fixture 성공으로 대체하지 않는다.
2. **단일 worker·정시 운용·복구 (오너3번)**: 프로필 소유권, 영속 결과 기록, 중단 위치별 재개/보류, DB 유실/중복 worker/절전/재부팅/연결 단절 대응. shadow 후 승인된 한 실행기만 쓰기;05/09/16준비,08/12/19공개 확인, 지나간 슬롯 skip, 결과/예외 알림. 저장 불명은 읽기 재조사이지 새 글 생성이 아니다. 로그인/MFA 보호는 owner boundary다.
3. **성과 기반 개선 (오너4번)**: 승인된 지표 수집, query/cluster별 추세, refresh, 비용/품질/실험의 비교·승격·rollback. 기존 게시글부터 시작할 수 있으며 실제 의사결정을 바꾸는 관찰 증거가 필요하다.
4. **저비용 실제 콘텐츠 생성 (오너2번)**: 출처 수집→최근24시간 적격 Top5→각 초안→선택 글과4개 자산→주장/권리/문체 검수. 합격 모델 중 총실행비용이 가장 낮은 것을 선택한다. 모델/검색/이미지 비용 상한과 실제 평가가 없으므로 현재 특정 최저가 모델 채택은 완료가 아니다.

오너 결정 ADR-048에 따라 위 순서는 원래 네 항목의 **1→3→4→2**다. 최종 생성기 연결 전에는 검수된 적격 패키지를 별도로 공급하며 없거나 오래된 슬롯은 건너뛴다. 정시 실행기가 있다고 새 이슈 생성까지 무인화됐다고 표현하지 않는다. FastAPI 운영 화면은 필요가 입증될 때 추가하며 위 항목을 지연시키는 필수 조건으로 만들지 않는다. Lighthouse/낭독/인쇄/외부광고/이미지 픽셀 검사는 owner 제외 상태를 유지한다.

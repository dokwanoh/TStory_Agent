# 수요 기반 재선정: AI 답변의 출처 확인

확인일: 2026-09-07. 결정: 작은 로컬 콘텐츠 실험으로 선택. 세계 최대 수요·검색량·예상 유입은 UNKNOWN.

## 근거와 한계

- [오픈서베이 블로그, AI 검색 트렌드 리포트 2026 하반기](https://blog.opensurvey.co.kr/trendreport/ai-search-2-2026/): 2026-07-02 전국 만 10~59세 남녀 1,000명 조사. 공개 요약은 AI 검색 이용 확산과 신뢰도 개선 여지를 함께 보여준다. 서비스 이용·평가 조사이며 특정 검색어의 검색량이나 우리 블로그의 방문 가능성을 측정하지 않는다. 원문 그래프·본문을 복제하지 않는다.
- [Google 공식 출처 도움말](https://support.google.com/gemini/answer/14143489?hl=ko): 출처 버튼이 없는 답변도 있다는 실제 사용상의 분기를 확인했다. 수요 규모의 증거가 아니라 해결할 문제와 현재 기능의 증거다.
- ConsumerInsight의 2026-03-12 보고서는 조사기관의 원문까지 확인했으나 용도 제한 고지가 있어 공개 글에 통계·도표를 재사용하지 않는다. 다른 조사와 모집단·기간이 달라 증가율도 계산하지 않는다.
- 실시간 Google Trends·연간 트렌드만으로 이번 개별 질문의 절대 검색량을 얻지 못했다. 숫자를 만들어 순위를 매기지 않는다.

## 실험 계약

선택 이유는 최대 검색량이 아니라 관측된 이용 맥락, 구체적 문제, 낮은 민감도, 지금 검증 가능한 독창적 설명의 교집합이다. AI 사용법 클러스터의 supporting article 후보이며 기존 블로그 스타일은 선택 조건이 아니다. 기존 자산과의 의미상 잠식 검토는 독립 검수에서 재확인한다.

로컬 성공 조건: 출처 유무 두 분기, 원문과 주장 대조법, 가상 사례임의 표시, 근거 불충분 시 보류, 확인 날짜, 공식 링크, 허위 사용 후기 0, 외부 쓰기 0. 시장 성공은 아직 평가 불가. 게시 승인과 성과 수집 승인 후에만 해당 URL의 질의·노출·클릭·정정 요청으로 가설을 평가한다. 검색량·CTR·수익 목표값은 베이스라인 전 UNKNOWN. 미관측을 0으로 채우지 않는다.
